Practical 05: Express.js Routing & CRUD Operations

Official curriculum lab manual covering RESTful HTTP methods, Express body parsing, URL parameters, status codes, and viva exam preparation.

Aim & Objective

To design and implement a standalone Express.js backend server demonstrating modular routing using express.Router() and full CRUD (Create, Read, Update, Delete) operations with proper HTTP status codes.

CRUD & HTTP Mapping

  • GET /api/products → 200 OK (Read all)
  • GET /api/products/:id → 200 OK or 404 (Read single)
  • POST /api/products → 201 Created (Create)
  • PUT /api/products/:id → 200 OK or 404 (Update)
  • DELETE /api/products/:id → 200 OK or 404 (Delete)
