## 🚀 Quick Execution Guide

### Frontend Practicals (01 to 04):
```bash
cd Practical-XX-Name
npm install
npm run dev
```

### Backend Practicals (05 to 09, 11):
```bash
cd Practical-XX-Name
npm install
npm start
```

### Full-Stack MERN Practicals (10, 12, 13):
Open two terminals in the practical's folder:
```bash
# Terminal 1: Backend Server
cd server
npm install
npm start

# Terminal 2: React Frontend Client
cd client
npm install
npm run dev
```
